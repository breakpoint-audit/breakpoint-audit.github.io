  • Retention. If your strategy passes verification, we retain the source code so you can access your own history and so we can show a track record. If it fails or is flagged, the code is held in a short-lived review queue (typically 14 days) and then permanently deleted — only an abstracted, non-proprietary pattern (never your actual code) is kept to improve future checks.

  • Your rights. You can request a copy of your data or request deletion of your account and associated data at any time — contact us below.
